Demystifying High-Speed Telemetry

Modern Formula 1 single-seaters carry over 300 onboard telemetry sensors generating millions of data points per lap. Standard consumer interfaces present superficial timing splits without exposing the physical forces that dictate race pace.

F1 Pokedex transforms raw GPS traces, gear selections, RPM curves, and throttle percentages into actionable insights. By coupling the FastF1 API with an indexed SQLite relational schema, the platform enables instantaneous delta analysis across any two drivers or seasons in Formula 1 history.

FastF1 Telemetry Extraction Pipeline

# FastF1 Real-Time Speed Trap & Delta Processing Engine
import fastf1 as ff1
import pandas as pd
import numpy as np

def evaluate_qualifying_delta(year: int, circuit: str, d1: str, d2: str):
    session = ff1.get_session(year, circuit, 'Q')
    session.load(telemetry=True, laps=True, weather=False)

    # Extract fastest qualifying flying laps
    lap_d1 = session.laps.pick_driver(d1).pick_fastest()
    lap_d2 = session.laps.pick_driver(d2).pick_fastest()

    # Synchronize high-frequency telemetry spatial points
    tel_d1 = lap_d1.get_telemetry().add_distance()
    tel_d2 = lap_d2.get_telemetry().add_distance()

    speed_delta = tel_d1['Speed'] - tel_d2['Speed']
    return {
        "delta_mean": float(np.mean(speed_delta)),
        "d1_apex_min": float(tel_d1['Speed'].min()),
        "d2_apex_min": float(tel_d2['Speed'].min()),
        "d1_time": lap_d1.LapTime,
        "d2_time": lap_d2.LapTime
    }
